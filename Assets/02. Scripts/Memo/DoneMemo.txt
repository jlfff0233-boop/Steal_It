* 기존 목표 점수 달성식 클리어는 폐기하고 제한 시간 동안 최대한 많은 점수를 모으는 방식으로 변경한다.

* 기존 장기 기획은 삭제하지 않고 아래쪽 참고 내용으로 유지한다.

# DECISION

# 확정된 기획 및 구조

# ==================================================

* 아이템은 단순 수집물이 아니라 상호작용 가능한 오브젝트이다.
* 아이템은 점수 획득과 물리/기믹 상호작용을 동시에 담당한다.
* 아지트는 별도 씬으로 구현한다.
* 직접 운반 시스템은 단계적으로 구현한다.
* 개발 기간은 약 1.5~2개월로 제한한다.
* Goal은 Inventory 아이템과 Interact 직접 운반 아이템을 모두 제출받는다.
* Inventory 아이템은 소지 상태로 제출하고, Interact 아이템은 직접 들고 Goal 영역에 가져가 제출한다.
* 직접 운반은 들기, 내려놓기, 밀기/당기기, 던지기를 구현한다.
* 끌기 시스템은 구현하지 않는다.
* 끌기 시스템은 줄이나 손잡이로 아이템을 뒤에서 끌고 다니는 지속형 드래그 이동을 뜻한다.
* 원형 아이템은 굴림 기반 물리 상호작용에 사용한다.
* 사각형 아이템은 발판, 스위치, 누름 기믹에 사용한다.
* 삼각형 아이템은 던지기 기반 함정 제거와 적 스턴에 사용한다.
* 던지기는 모든 ShapeType 아이템이 가능하지만, 삼각형 아이템은 다른 모양보다 스턴 시간이 길다.
* 밀기/당기기는 사각형 아이템만 가능하다.
* 내려놓을 위치가 막혀 있으면 내려놓기를 실패 처리한다.
* 아이템이 끼이면 플레이어 근처의 유효한 바닥 위치로 복귀시킨다.
* 스위치는 스테이지별로 다른 조건 타입을 사용할 수 있다.
* 스위치 조건 타입은 Weight 조건, ShapeType 조건, Weight 합산 조건을 후보로 둔다.
* 적 스턴은 특정 아이템 충돌로 발생하며, 스턴 중에는 추격을 중단한다.
* 콤보 위험 증가는 적 의심 증가와 추격 위험 보상에 연결한다.
* Inventory 아이템도 자동 획득이 아니라 상호작용 키 입력으로 획득한다.
* Goal 제출은 상호작용 키 입력식으로 처리한다.
* 입력 우선순위는 E, R, F 순서로 본다.
* 같은 범위에 여러 대상이 있을 때 상호작용 우선순위는 제출, 들고 있는 아이템, 바닥 아이템, 기믹 순서이다.
* 던지기 조준은 마우스 조준으로 처리한다.
* 콤보는 시간 제한이 아니라 발각/상자 개봉 발각/상자 피격 누적/피격 등 위험 이벤트로 해제한다.
* 스테이지 클리어는 제한 시간 생존과 최저 목표 점수 달성을 함께 사용한다.
* 세분화된 스위치 조건 타입은 Stage 4 이후부터 보여준다.

## [아이템 시스템]

* 목적: 아이템을 점수 획득 대상이자 스테이지 공략 도구로 사용한다.
* 플레이 경험: 가벼운 아이템은 빠르게 회수 / 무거운 아이템은 운반 리스크와 높은 보상 / 직접 운반 아이템은 퍼즐 해결과 위험 보상에 사용
* 핵심 규칙: CarryType은 운반과 제출 방식 / ShapeType은 물리와 기믹 역할 / ValueType은 점수와 콤보 보상 / Weight는 이동속도, 점프, 밀기, 던지기 패널티

## [CarryType]

* Inventory: E 입력으로 획득 / Goal에서 Hero 기준 제출 / 물리 기믹 역할 없음 / 빠른 수집과 점수 획득 / 최대 소지 무게 제한 있음
* Interact: 자동 습득 금지 / 들기, 밀기, 던지기 대상 / Goal에서 아이템 기준 제출 / 기믹 해결, 적 스턴, 위험 보상 / 최대 소지 무게 제한 없음

## [Weight]

* Light: 주로 Inventory / 체감 패널티 미세 / 점수 배율 낮거나 기본값
* Medium: 주로 Interact 기본 무게 / 체감 패널티 약간 느려짐 / Stage 2 직접 운반 학습용
* Heavy: Interact 고위험 고보상 / 체감 패널티 확실히 느림 / 점수 계산식에서 무게 배율 보상
* 수치 관리: 이동속도 감소량 / 점프력 감소량 / 점수 배율 / 던지기 거리, 속도, 쿨타임은 ScriptableObject 또는 외부 튜닝값으로 조절

## [ShapeType]

* Circle: 굴림 기반 물리 상호작용 / 경사로, 굴러가는 발판, 원거리 스위치 자극 / 밀기와 당기기 대상 아님 / 상호작용 해제 시 정지 처리
* Square: 안정적인 받침과 누름 기믹 / 발판, 스위치, 임시 계단, 무게 누름 장치 / MVP 기준 밀기와 당기기 가능
* Triangle: 던지기 기반 공격적 상호작용 / 함정 제거, 적 스턴, 위험 구간 돌파 / 다른 ShapeType보다 긴 스턴 시간

## [Goal 제출]

* 목적: Inventory와 Interact를 하나의 제출 루프인 점수, 콤보, 판매로 연결한다.
* 제출 대상: Inventory에 들어간 아이템 / Hero가 직접 들고 있는 Interact 아이템 / Goal 영역 안에 놓인 Interact 아이템
* 성공 조건: Goal 판정 범위 안 / 중복 제출 아님 / CarryType에 맞는 제출 조건 만족 / 제한 시간 또는 실패 조건에 걸리지 않음 / E 입력 제출
* 결과: 점수 반영 / 콤보 갱신 / 제출 아이템 축소와 투명화 후 제거 / 판매 또는 요리 결과 전달 / 실패 시 아이템 흩뿌림

## [직접 운반]

* 들기: Interact 아이템 직접 소지 / 무게 패널티 적용 / 이동, 점프, 던지기, 내려놓기만 가능 / 오르기와 타기류 불가
* 내려놓기: 현재 위치 근처 배치 / 발판, 스위치, 엄폐물, Goal 제출에 사용 / 막힌 위치면 실패 / 끼임 상태면 플레이어 근처 유효 바닥으로 복귀
* 밀기/당기기: 사각형만 가능 / 수평 이동 중심 / 이동속도 저하와 적 회피 리스크 / 지속형 드래그 이동은 제외
* 던지기: 모든 ShapeType 가능 / 마우스 조준 / 무게별 거리, 속도, 쿨타임 / 회수 가능 / 손상 시 제출 점수 영향 / 삼각형은 긴 스턴 시간

## [적 의심/추격/스턴]

* 의심: 제출 누적, 상자 개봉 발각, 상자 피격 누적, 콤보 위험 증가와 연결 / 콤보가 높을수록 모든 적 감지 영역 증가 / 들고 이동 자체는 적 영역 밖에서 의심 증가 없음
* 추격: ItemBox 이벤트와 Enemy 추격 구조 활용 / 적 영역 안에서 ItemBox를 열면 100% 추격 / 감지 영역 이탈 또는 숨기로 해제 가능 / 추격 중 제출 보너스 가능
* 스턴: 던진 아이템 충돌로 발생 / Circle 가장 짧음, Square 보통, Triangle 가장 김 / 무게와 가치가 높을수록 소폭 증가 / 최대 2회 연속 / 이후 스턴 불가 쿨타임 / 완전 정지 후 감지 상태에 따라 복귀

## [콤보/위험 보상]

* 증가 조건: 아이템 제출 성공 / 고가치 아이템 제출 / Interact 제출은 Inventory보다 높은 보너스
* 위험 증가: 콤보가 높을수록 모든 적 감지 영역 증가 / 추격 중 제출 보너스 / 무거운 아이템 제출 보너스 후보
* 해제 조건: 시간 제한 없음 / 운반 중 발각, 상자 개봉 발각, 상자 피격 누적, 피격, 목숨 감소, 스테이지 실패 시 해제

## [요리/판매]

* MVP: 제출된 아이템의 점수와 ValueType을 기반으로 판매 결과 생성 / 복잡한 레시피 조합 제외 / 아지트 씬에서 정산 확인
* 확장: 특정 조합 보너스 / 스테이지별 추천 판매 품목 / 보상 화면 연출

## [ItemData]

* 확인 기준: CarryType은 Inventory와 Interact 운반 방식 구분 / ShapeType은 Circle, Square, Triangle 기믹 역할 구분 / ValueType은 점수와 콤보 보상 연결 / Weight는 이동, 점프, 밀기, 던지기 패널티 연결 / ScoreData는 점수 계산만 담당

## [Hero 상호작용]

* 확인 기준: E는 줍기, 들기, 제출, 기본 상호작용 / R은 내려놓기와 상호작용 해제 / F는 던지기 / 대상 우선순위는 제출 > 들고 있는 아이템 > 바닥 아이템 > 기믹

## [Goal 제출]

* 확인 기준: Inventory 제출과 Interact 제출 모두 처리 / Inventory는 Hero 기준 판정 / Interact는 아이템 위치 기준 판정 / 중복 제출 방지 / 제출 성공 시 Score, Combo, Sale 또는 Cooking 결과 연결

## [물리 기믹]

* 확인 기준: Circle은 굴림과 스위치 자극 / Square는 발판과 스위치 누름 / Triangle은 던져서 충돌 이벤트 / 스위치 조건은 Weight, ShapeType, Weight 합산 중 선택 / 세분화 조건은 Stage 4부터 노출

## [EnemyStun]

* 확인 기준: 스턴 발생 조건은 아이템 충돌 / 모든 ShapeType 던지기로 스턴 가능 / Triangle은 긴 스턴 시간 / 스턴 중 Enemy 추격 중단 / 종료 후 감지 상태에 따라 복귀 / 벽 너머 피격과 반복 피격 방지

## [Combo]

* 확인 기준: 제출 성공 시 갱신 / 시간 제한으로 끊지 않음 / 콤보가 높을수록 모든 Enemy 감지 영역 증가 / 추격 중 제출, 무거운 아이템 제출, Interact 제출은 위험 보상 후보 / 발각, 상자 개봉 발각, 상자 피격 누적, 피격 시 해제

## [Stage]

* 확인 기준: Stage 1은 Inventory 수집과 Goal 제출 / Stage 2는 Interact 들기, 내려놓기, 사각형 스위치 / Stage 3은 원형 굴림과 사각형 밀기/당기기 / Stage 4는 삼각형 던지기, 함정 제거, 적 스턴, 세분화 스위치 조건 / 각 스테이지는 새 규칙 1개와 복습 규칙 1개 중심
