# MEMO_RULE

# 메모 파일 사용 규칙

# ==================================================

* 현재 프로젝트 상태는 Memo 폴더의 DoneMemo.txt와 TodoMemo.txt를 기준으로 판단한다.
* DoneMemo.txt는 확정 결정, 시스템 기준, 완료 작업, 변경 이력을 관리한다.
* TodoMemo.txt는 미구현 시스템, 앞으로 할 일, 세부 수치/판정 확정 필요 항목을 관리한다.
* 과거 대화 내용과 메모 내용이 충돌할 경우, 반드시 사용자에게 질문부터 한다.
* 우선순위는 CURRENT_DECISION / CURRENT_TODO / DECISION / DONE / LOG / TODO / 현재 대화 순서로 본다.
* 같은 성격의 하위 항목은 세로로 길게 나열하지 않고 "/"로 병렬 정리한다.
* Unity 메타 파일(.meta)은 생성, 수정, 삭제하지 않는다.

# ==================================================

# FILE_ROLE

# 파일별 역할

# ==================================================

* DoneMemo.txt: CURRENT_DECISION / CURRENT_SYSTEM_SPEC / DECISION / SYSTEM_SPEC / IMPLEMENTATION_GUIDE / DONE / LOG
* TodoMemo.txt: CURRENT_TODO / CURRENT_IMPLEMENTATION_PLAN / UNIMPLEMENTED_SYSTEMS / TODO / NEED_DETAIL / QUESTION

# ==================================================

# NOTE

# 과거 RuleMemo 내용 처리

# ==================================================

* 기존 RuleMemo에 있던 초기 기획 메모는 현재 확정 기획과 충돌 가능성이 있어 기준 문서에서 제외한다.
* 최신 확정 기획은 DoneMemo.txt의 CURRENT_DECISION과 CURRENT_SYSTEM_SPEC를 따른다.
* 최신 작업 목록은 TodoMemo.txt의 CURRENT_TODO와 CURRENT_IMPLEMENTATION_PLAN을 따른다.
* 기존 DECISION / SYSTEM_SPEC / TODO는 삭제하지 않고 장기 계획 참고용으로 아래쪽에 둔다.
